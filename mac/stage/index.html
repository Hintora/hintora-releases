Published 10 Sep 2026, 23:28 UTC · 4.9 MB · macOS 14.0 or later · Release candidates, one step before production.

Test build. Apple hasn’t notarized Hintora yet, so macOS asks before the first launch: right-click Hintora Installer, choose Open, then Open again. If it’s still blocked, allow it in System Settings → Privacy & Security.

Install

  1. Download and open Hintora-Installer.zip.
  2. Open Hintora Installer and click Install. Hintora moves into your Applications folder and opens.
  3. Follow the notch to allow Microphone and Screen Recording.
  4. Hold Control + Option, ask your question, and let go.

Updates

  • This channel updates itself. A copy installed from here follows the stage channel.
  • Update in the notch. When a build is ready, the notch shows Update; Hintora restarts on it.
  • Switch channels by running another channel’s installer.
