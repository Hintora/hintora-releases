# Hintora releases

Public downloads and update feeds for Hintora. This repository holds no source
code: everything here is produced by Hintora's release pipeline.

- **Download for macOS:** https://github.com/Hintora/hintora-releases/releases/latest/download/Hintora-Installer.zip
- **Update feeds:** `https://hintora.github.io/hintora-releases/macos/<channel>/appcast.xml`
  for the `dev`, `staging` and `production` channels.

Never upload, edit or delete files here by hand. Appcasts are signed, and every
published archive is immutable — clients verify both.
